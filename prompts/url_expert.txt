STEP 2 — TYPOSQUATTING ANALYSIS

Process ONLY labels flagged as TYPOSQUATTING CANDIDATES in the Pre-Step.

RECONSTRUCTION RULE:
For each candidate label, attempt to reconstruct the original brand name by
applying the minimum number of character-level operations. Accepted operations:

  • Transposition: two adjacent characters swapped inside the brand token.
    Example: "paylap" → swap positions 4-5 → "paypal" ✓
  • Omission: one character dropped from inside the brand token.
    Example: "amazn" → insert missing 'o' → "amazon" ✓
  • Substitution (homoglyph): one character replaced by a visually similar one.
    Example: "micros0ft" → '0' → 'o' → "microsoft" ✓

A typosquat candidate requires exactly one allowed edit operation, unless otherwise specified.

The reconstruction MUST produce an EXACT match to a known brand name.
If reconstruction succeeds → classify as TYPOSQUATTING.

For each finding, state:

  - The operation applied and characters involved

CONTEXT RULE: For each label, identify candidate brand-bearing tokens. Ignore surrounding contextual tokens such as api, v2, login, secure, prod, numeric IDs, etc. Do not remove characters from the candidate brand token itself.

⚠️ SEQUENCING RULE: A label classified as TYPOSQUATTING here is CLOSED.
Do NOT carry it to Step 3 under any circumstances.
